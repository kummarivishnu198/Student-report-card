# Project Overview

## Title
Student Report Card Management System using C++ and SQLite

## Problem statement
Manual preparation of student report cards can be time-consuming and can lead to calculation and record-keeping errors. This application stores student details and subject marks in a database and calculates report-card summaries automatically.

## Objectives
- Maintain student records in a structured database.
- Store and update subject-wise marks.
- Calculate totals, percentages, and grades consistently.
- Search and retrieve student reports quickly.

## Suggested team division
- Member 1: Student model, menu, and input validation.
- Member 2: SQLite database layer and CRUD operations.
- Member 3: Report-card calculations, testing, README, and presentation.

All team members should understand the complete program before the demonstration.

## Future enhancements
- Admin and faculty login with role permissions
- Attendance and semester-wise history
- PDF report-card export
- CSV import/export
- Automated database backup
